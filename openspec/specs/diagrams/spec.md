# diagrams Specification

## Purpose

Рендерит ограниченное, осознанно упрощённое подмножество синтаксиса Mermaid и PlantUML в inline SVG прямо на этапе сборки, без внешних библиотек и без обращения в интернет.

## Requirements

### Requirement: Поддерживаемые типы диаграмм Mermaid
Система SHALL распознавать и рендерить только `flowchart`/`graph` (с направлениями `TD`, `TB`, `BT`, `LR`, `RL`, по умолчанию `TD`) и `sequenceDiagram`; остальные типы Mermaid-диаграмм (например, `classDiagram`, `gantt`, `pie`) система SHALL не рендерить, возвращая признак неудачи вызывающему коду.

#### Scenario: Flowchart без явного направления
- **WHEN** диаграмма начинается со строки `graph`
- **THEN** используется направление по умолчанию `TD`

#### Scenario: Неподдерживаемый тип
- **WHEN** диаграмма начинается со строки `pie`
- **THEN** функция рендера возвращает falsy-значение, и вызывающий код обязан откатиться на обычный блок кода

### Requirement: Поддерживаемые типы диаграмм PlantUML
Система SHALL распознавать и рендерить только sequence-диаграммы, ограниченные блоком `@startuml ... @enduml`; прочие виды PlantUML-диаграмм система SHALL не рендерить.

#### Scenario: PlantUML sequence-диаграмма
- **WHEN** диаграмма содержит `@startuml` ... `@enduml` с обменом сообщениями между участниками
- **THEN** генерируется SVG с последовательностью сообщений

### Requirement: Автономный layout без внешних зависимостей
Система SHALL вычислять раскладку диаграммы (ширину текста, перенос по словам, позиционирование узлов и связей) собственными эвристиками, не используя DOM/canvas или внешние библиотеки, и без сетевых запросов.

#### Scenario: Длинная подпись узла
- **WHEN** подпись узла превышает расчётную максимальную ширину
- **THEN** подпись переносится на несколько строк внутри SVG-текста

### Requirement: Результат — inline SVG
Успешно распознанная диаграмма SHALL рендериться как `<div class="db-diagram"><svg>...</svg></div>`, встраиваемый прямо в HTML страницы без отдельных файлов изображений.

#### Scenario: Диаграмма на странице
- **WHEN** страница содержит валидную flowchart-диаграмму
- **THEN** в итоговом HTML страницы присутствует inline `<svg>` без внешних ссылок на файлы диаграмм
