# export-md Specification

## Purpose

Преобразует markdown-контент dockbook (с его кастомными блоками) в обычный портируемый markdown без специфичного синтаксиса, пригодный для вставки в системы вроде Confluence.

## Requirements

### Requirement: Полная пересборка папки экспорта
Экспорт SHALL полностью удалять и заново создавать целевую папку перед записью экспортированных файлов.

#### Scenario: Повторный экспорт
- **WHEN** целевая папка экспорта уже содержит файлы от предыдущего запуска
- **THEN** после экспорта в ней остаются только файлы текущего запуска

### Requirement: Сохранение структуры content-разделов
Для каждого content-раздела конфигурации экспорт SHALL записывать результат в подпапку целевой директории, соответствующую `base` раздела (корень раздела `/` экспортируется прямо в корень целевой папки).

#### Scenario: Раздел с base отличным от корня
- **WHEN** content-раздел имеет `base: '/guide'`
- **THEN** его содержимое экспортируется в `<outDir>/guide`

### Requirement: Стандартные конструкции переносятся без изменений
Обычные markdown-конструкции (заголовки, списки, таблицы, обычные код-блоки, ссылки, инлайн-форматирование) SHALL переноситься в вывод дословно, без изменений.

#### Scenario: Обычный абзац
- **WHEN** исходный файл содержит обычный markdown-абзац без кастомных блоков
- **THEN** экспортированный файл содержит тот же текст без изменений

### Requirement: Трансформация кастомных блоков
Экспорт SHALL преобразовывать кастомные блоки dockbook в эквивалентную обычную markdown-разметку: `hint` → цитата с жирным заголовком; `tabs`/`accordion` → последовательность заголовков `####` с содержимым каждой вкладки/секции; `code-group` → последовательность обычных код-блоков, каждый с подписью `**label**` перед ним при наличии `label`; `cards` → жирная ссылка-заголовок с телом; `steps` → развёрнутое содержимое без спец-обёртки; `mermaid`/`plantuml` → код-блок с исходным текстом диаграммы и соответствующим языком (без рендера в изображение); любой неизвестный кастомный блок → развёрнутое содержимое без обёртки.

#### Scenario: Блок hint
- **WHEN** исходный файл содержит `::hint{type="warning" title="Осторожно"} ... ::`
- **THEN** экспортированный markdown содержит цитату вида `> **Осторожно**` с содержимым внутри

#### Scenario: Диаграмма mermaid
- **WHEN** исходный файл содержит `::mermaid ... ::` с диаграммой
- **THEN** экспортированный файл содержит обычный код-блок ` ```mermaid ` с тем же текстом диаграммы (не изображение)

### Requirement: Заголовок из frontmatter
Если исходный файл содержит `title` во frontmatter, а тело после трансформации не начинается с заголовка первого уровня, экспорт SHALL добавлять `# <title>` в начало результата.

#### Scenario: Frontmatter с title, тело без заголовка
- **WHEN** файл имеет `title: "Обзор"` во frontmatter и тело начинается сразу с абзаца
- **THEN** экспортированный файл начинается со строки `# Обзор`

### Requirement: Не-markdown файлы копируются как есть
Файлы, не являющиеся `.md`/`.mdx`, SHALL копироваться в целевую папку без изменений; файлы, начинающиеся с `.`, SHALL пропускаться.

#### Scenario: Изображение в content-папке
- **WHEN** content-папка содержит `diagram.png`
- **THEN** файл копируется в соответствующее место целевой папки без изменений содержимого

### Requirement: Переименование .mdx в .md
Экспортированные файлы с исходным расширением `.mdx` SHALL сохраняться с расширением `.md`.

#### Scenario: Исходный файл .mdx
- **WHEN** исходный файл называется `page.mdx`
- **THEN** экспортированный файл называется `page.md`
