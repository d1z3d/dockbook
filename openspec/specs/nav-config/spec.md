# nav-config Specification

## Purpose

Хранит пользовательские заголовки и порядок папок сайдбара централизованно в `dockbook.config.json`, чтобы content-папки не засорялись служебными файлами и переименования папок сохранялись между пересборками.

## Requirements

### Requirement: Расположение и формат файла
Система SHALL хранить метаданные папок в файле `dockbook.config.json`, расположенном рядом с `dockbook.config.js` (в `config.root`), в формате `{ "folders": { "<key>": { "title"?, "order"? } } }`.

#### Scenario: Файл отсутствует
- **WHEN** `dockbook.config.json` не существует
- **THEN** система считает, что метаданных папок нет, и не выбрасывает ошибку

#### Scenario: Файл повреждён
- **WHEN** `dockbook.config.json` существует, но содержит невалидный JSON
- **THEN** система тихо возвращает пустой набор метаданных вместо ошибки

### Requirement: Ключ записи папки
Ключ записи SHALL строиться из `base` content-раздела и относительного пути папки внутри раздела на диске; пустой относительный путь SHALL означать корень раздела и использовать сам `base` как ключ.

#### Scenario: Корневая папка раздела
- **WHEN** запрашиваются метаданные для корня content-раздела с `base: '/guide'`
- **THEN** используется ключ `/guide`

#### Scenario: Вложенная папка
- **WHEN** запрашиваются метаданные для папки `advanced` внутри раздела с `base: '/guide'`
- **THEN** используется ключ `/guide/advanced`

### Requirement: Обновление заголовка папки
Система SHALL предоставлять операцию, которая точечно устанавливает или удаляет поле `title` для конкретной папки, не затрагивая поле `order` и записи других папок.

#### Scenario: Установка заголовка
- **WHEN** для папки задаётся непустой заголовок
- **THEN** соответствующая запись в `folders` получает/обновляет поле `title`, файл перезаписывается с отступом 2 пробела

#### Scenario: Очистка заголовка
- **WHEN** для папки заголовок устанавливается в пустую строку
- **THEN** поле `title` удаляется из записи; если запись становится пустой, она удаляется из `folders`

### Requirement: Удаление файла при отсутствии метаданных
Система SHALL удалять `dockbook.config.json`, если после изменения `folders` становится пустым объектом.

#### Scenario: Последняя запись удалена
- **WHEN** удаляется единственная оставшаяся запись в `folders`
- **THEN** файл `dockbook.config.json` удаляется с диска
