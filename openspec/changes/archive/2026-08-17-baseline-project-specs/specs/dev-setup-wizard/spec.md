## Purpose

Проводит пользователя, у которого ещё нет `dockbook.config.js`, через выбор папки документации прямо в браузере, и создаёт для него рабочий конфиг без ручного редактирования файлов.

## ADDED Requirements

### Requirement: Мастер запускается при отсутствии конфига
При выполнении `dockbook dev` в папке без `dockbook.config.js`/`.cjs`, CLI SHALL поднять временный HTTP-сервер на порту по умолчанию (4000) вместо обычного dev-сервера.

#### Scenario: Первый запуск без конфига
- **WHEN** пользователь выполняет `dockbook dev` в пустой папке
- **THEN** запускается временный сервер, и в консоль печатается адрес `http://localhost:<port>` для выбора папки документации

### Requirement: Отдача приветственного экрана
Временный сервер SHALL отдавать статические файлы из `assets/`, при этом любой неизвестный путь (включая `/`) SHALL приводить к отдаче `welcome.html`.

#### Scenario: Запрос корня
- **WHEN** браузер запрашивает `/`
- **THEN** сервер отвечает содержимым `assets/welcome.html`

#### Scenario: Запрос несуществующего файла
- **WHEN** браузер запрашивает путь, которого нет в `assets/`
- **THEN** сервер отвечает содержимым `welcome.html` (SPA-фоллбек)

#### Scenario: Попытка выхода за пределы assets
- **WHEN** запрошенный путь резолвится за пределы директории `assets/`
- **THEN** сервер отвечает 403 Forbidden

### Requirement: Просмотр файловой системы
Мастер SHALL предоставлять `GET /__dockbook_api/browse?path=` для навигации по директориям при выборе папки документации, возвращая список поддиректорий, родительский путь, домашнюю папку и количество markdown-файлов в текущей папке.

#### Scenario: Запрос без пути
- **WHEN** вызван `GET /__dockbook_api/browse` без параметра `path`
- **THEN** сервер возвращает содержимое домашней директории пользователя

### Requirement: Инициализация конфигурации
Мастер SHALL предоставлять `POST /__dockbook_api/init` с телом `{ path }`, который валидирует, что `path` — существующая директория, создаёт `dockbook.config.js` с одним content-разделом на эту папку, и переключается на обычный `dev`-режим.

#### Scenario: Успешная инициализация
- **WHEN** отправлен `POST /__dockbook_api/init` с существующей директорией и конфиг ещё не создан
- **THEN** сервер создаёт `dockbook.config.js` (title `Dockbook`, `outDir: dist`, content-раздел на выбранную папку), закрывает временный сервер и запускает обычный dev-сервер

#### Scenario: Путь не является директорией
- **WHEN** отправлен `POST /__dockbook_api/init` с несуществующим или не-директорным путём
- **THEN** сервер отвечает 400 `not_a_directory`

#### Scenario: Конфиг уже существует
- **WHEN** отправлен `POST /__dockbook_api/init`, но `dockbook.config.js`/`.cjs` уже присутствует в папке
- **THEN** сервер отвечает 409 `config_exists` и не перезаписывает файл
