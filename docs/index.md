# dockbook

**dockbook** — локальный инструмент документации: markdown-файлы превращаются
в статический сайт с сайдбаром, поиском, тёмной темой и справочником по
OpenAPI. Внешний вид и поведение — как у GitBook, но без облака, без базы
данных и без UI-фреймворков.

::hint{type="info"}
Эта страница сама отрендерена dockbook'ом из файла `docs/index.md` в корне
репозитория — инструмент документирует сам себя.
::

## Ключевые свойства

::cards
::card{title="Ни одной БД" to="/guide/configuration"}
Весь контент — файлы `.md`/`.mdx` в git. Состояние сайта не хранится нигде,
кроме файловой системы.
::
::card{title="Ноль фреймворков" to="/reference/architecture"}
Сборщик — чистый Node.js (только встроенные модули `fs`, `path`, `http`).
Фронтенд — чистые HTML/CSS/JS без единой библиотеки.
::
::card{title="Работает офлайн" to="/guide/installation"}
После запуска сайт не делает ни одного запроса за пределы `localhost` —
ни шрифтов, ни аналитики, ни CDN.
::
::card{title="Свои папки в доках" to="/guide/content"}
В `dockbook.config.js` перечисляются папки, которые должны попасть в
документацию — можно подключить сколько угодно.
::
::
