# Поиск

Поиск (кнопка в шапке или `Cmd+K` / `Ctrl+K`) работает полностью в браузере,
без сервера поиска и без сети.

## Индекс

При сборке для каждой страницы (markdown и сгенерированных OpenAPI) в
`data/search.json` записывается заголовок, описание из frontmatter и
текст страницы без разметки — до 4000 символов. Файл лежит рядом с сайтом
и подгружается лениво, при первом открытии поиска, а не при загрузке
страницы.

## Ранжирование

Запрос разбивается на слова. Для каждой страницы считается очень простой
скор:

- совпадение слова в заголовке — `+10`;
- заголовок начинается со слова — дополнительно `+5`;
- каждое вхождение слова в текст страницы — `+1`.

Страницы с нулевым скором в выдачу не попадают, остальные сортируются по
убыванию скора, показываются первые 20. Совпадения подсвечиваются в
заголовке и сниппете результата.

## Ограничения

Это не полнотекстовый движок с морфологией и опечатками — поиск по
подстроке, регистронезависимый. Для локальной документации на одном
проекте этого обычно достаточно; если нужен более умный поиск, `search.json`
— обычный статический файл, его несложно скормить любому другому клиентскому
поисковому индексу.
