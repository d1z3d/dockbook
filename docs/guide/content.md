# Контент и структура

Документация — это файлы `.md`/`.mdx` внутри папок, перечисленных в
[`content`](/guide/configuration). Никакой базы данных: структура сайдбара и
маршруты строятся прямо из файловой системы при каждой сборке.

## Как путь к файлу становится маршрутом

```
docs/
  index.md            → /
  showcase.md         → /showcase
  guide/
    setup.md           → /guide/setup
```

- `index.md` в папке становится «индексной» страницей этой папки (её
  маршрут — маршрут самой папки), а не отдельным пунктом меню.
- Любой другой файл превращается в маршрут по своему пути без расширения.
- Если раздел подключён не в корень (`base: '/notes'`), этот префикс
  добавляется ко всем маршрутам папки.

## Frontmatter

В начале файла — YAML-блок между `---`:

```md
---
title: Быстрый старт
description: Установка и первый запуск
order: 1
---

# Быстрый старт
...
```

| Поле | Назначение |
| --- | --- |
| `title` | Заголовок в сайдбаре, `<title>` вкладки, заголовок в поиске. Если не задан — берётся текст первого заголовка `#` в файле, а если и его нет — имя файла. |
| `description` | Показывается как сниппет в результатах поиска. |
| `order` | Число, задаёт порядок среди соседних файлов/папок. Без `order` элементы сортируются по алфавиту, после элементов с `order`. |

## `.navigation.yml` — заголовок и порядок папки

Файл `.navigation.yml` внутри папки настраивает саму папку как раздел
сайдбара:

```yaml
title: Guide
order: 2
```

- `title` — заголовок раздела в сайдбаре (если в папке нет `index.md`, у
  которого можно было бы взять заголовок).
- `order` — порядок папки среди соседних файлов и папок, работает так же,
  как `order` в frontmatter страницы.

## Вложенность

Папки можно вкладывать сколь угодно глубоко — каждая подпапка становится
вложенным разделом в сайдбаре с собственным `.navigation.yml` (необязательным).

У каждого раздела в сайдбаре есть стрелка-шеврон слева от названия — клик
по ней сворачивает/разворачивает вложенные страницы, не переходя по
ссылке раздела. Состояние сохраняется в `localStorage` браузера и
переживает перезагрузку страницы (у каждого посетителя — своё, в файлах
на диске ничего не меняется).

## `.mdx` и скрытые файлы

Файлы `.mdx` обрабатываются тем же парсером, что и `.md` — синтаксис
блоков (`::hint`, `::tabs`...) идентичен, JSX-вставки не поддерживаются.
Файлы и папки, начинающиеся с точки (кроме служебного `.navigation.yml`),
при сканировании пропускаются.
