# Экспорт в Confluence

Confluence (и большинство других систем импорта markdown) не понимает
блочный синтаксис dockbook — `::hint`, `::tabs`, `::steps`, `::accordion`,
`::cards`, `::code-group`. Команда `export-md` собирает контент из
`content`, но вместо HTML-сайта пишет обычные `.md`-файлы, где все
кастомные блоки развёрнуты в стандартный markdown.

```bash
node bin/dockbook.js export-md
```

## Куда попадают файлы

По умолчанию — в папку `confluence` рядом с `dockbook.config.js`
(`<config.root>/confluence`). Структура повторяет `content`-разделы:
подпапки и файлы `.md`/`.mdx` → `.md`, картинки и другие ассеты копируются
рядом без изменений.

Другую папку можно указать первым аргументом (путь — относительно текущей
рабочей директории):

```bash
node bin/dockbook.js export-md ./confluence-export
node bin/dockbook.js export-md /абсолютный/путь
```

::hint{type="warning"}
При каждом запуске целевая папка полностью пересоздаётся (старое
содержимое удаляется перед записью) — не храните в ней ничего, что не
попадает туда через `export-md`.
::

## Что происходит с блоками

| Было | Стало |
| --- | --- |
| `::hint{type="warning"}...::` | Цитата: `> **Внимание**` + текст |
| `::tabs` / `::tab{label="..."}` | Заголовок `####` с названием вкладки перед содержимым каждой вкладки |
| `::code-group` с `[label]` у блоков кода | `**label**` перед каждым блоком кода |
| `::steps` | Обёртка снимается, вложенные `### Шаг` остаются как есть |
| `::accordion` / `::accordion-item{label="..."}` | Заголовок `####` + текст |
| `::cards` / `::card{title="..." to="..."}` | `**[Заголовок](ссылка)**` + описание |
| `::mermaid` / `::plantuml` | Обычный код-фенс ```` ```mermaid ```` / ```` ```plantuml ```` (без рендера в SVG) |
| Неизвестный блок `::имя` | Обёртка снимается, содержимое остаётся как есть |
| Frontmatter (`title`, `description`, `order`) | Вырезается; если в тексте нет заголовка `#`, `title` превращается в `# Заголовок` |

Всё остальное — заголовки, списки, таблицы, обычные код-блоки, ссылки,
инлайн-форматирование — переносится дословно, без изменений.

## Через package.json

```json
{
  "scripts": {
    "docs:export-md": "node bin/dockbook.js export-md"
  }
}
```
