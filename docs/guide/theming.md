# Тема и оформление

У dockbook нет темизатора и настроек в конфиге — перекраска делается одним
файлом `theme.css`, который лежит рядом с `dockbook.config.js`.

## Как это работает

При сборке, если рядом с конфигом есть `theme.css`, он копируется в
собранный сайт и подключается в `index.html` **после** основного
`app.css`. Поэтому достаточно переопределить нужные CSS-переменные —
остальное наследуется.

```css
/* theme.css */
:root {
  --db-accent: #e0453c;
}

[data-theme='dark'] {
  --db-accent: #ff6b61;
}
```

::hint{type="info"}
Если файла `theme.css` нет, dockbook создаст пустой при сборке — можно
сразу писать в него переменные.
::

## Доступные переменные

Полный список — в `assets/app.css` инструмента, ключевые:

| Переменная | За что отвечает |
| --- | --- |
| `--db-accent` | Акцентный цвет: ссылки, активные пункты меню, кнопки. |
| `--db-bg` / `--db-bg-alt` | Фон страницы / фон подложек (код, карточки, хиты). |
| `--db-fg` / `--db-fg-muted` | Основной и приглушённый цвет текста. |
| `--db-border` | Цвет рамок и разделителей. |
| `--db-code-bg` | Фон блоков кода. |
| `--db-radius` | Скругление углов у карточек, кнопок, подсказок. |
| `--db-sidebar-w` / `--db-toc-w` | Ширина сайдбара и колонки оглавления. |
| `--db-font` / `--db-font-mono` | Шрифтовые стеки — по умолчанию системные, без загрузки внешних шрифтов. |

## Тёмная и светлая тема

Тема переключается атрибутом `data-theme` на `<html>` и хранится в
`localStorage` (`db-theme`). Значения по умолчанию для тёмной темы заданы в
`assets/app.css` под селектором `[data-theme='dark']` — в `theme.css`
переопределяются точно так же, своим блоком под этим селектором.

Тема выбирается автоматически при первом заходе по системной настройке
(`prefers-color-scheme`), дальше — по выбору пользователя, без «мигания»
при загрузке (переключатель темы применяется инлайн-скриптом в `<head>`
до отрисовки страницы).
